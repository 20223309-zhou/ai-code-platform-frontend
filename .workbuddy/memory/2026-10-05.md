### 追加：修复"下拉文字不居中" + 整页卡顿
**1) 文字不居中 —— 根因是 antd 的基线伪元素**
- 查 `node_modules/ant-design-vue/es/select/style/single.js`：`-selection-item/-placeholder` 是 `position:relative` + `lineHeight = controlHeight - 2`（small=22px），且带 `::after{display:inline-block;width:0;content:"\a0"}` 用于基线对齐。
- 该 `::after` 会撑高行盒（约 +6px），使文字在 30px 盒子里**偏上** → 视觉"没居中"。
- 修：`-selector` 与 `-selection-item/-placeholder` 改用 `display:flex; align-items:center; height:30px; line-height:1`，并 `::after{display:none}`。单选值不受 `text-overflow` 影响，安全。

**2) 整页卡顿 —— 4 个全屏常驻动画层 + 其上的 backdrop-filter**
- 元凶：`body::before` 极光（`aurora-drift 80s` 动 `background-position`+`filter`，全屏逐帧重绘）；`.bg-dynamic-global::before/::after` 两层满屏光幕（`blur(36px)` + `light-curtain*` 无限动画 + `will-change`）；顶栏 `.logo-shell` 常驻 `breathe` 动画（逐帧重绘 `box-shadow`）。
- 机理：全屏背景在动 → 上层所有 `backdrop-filter` 元素每帧重新采样模糊 → 掉帧。
- 修：① 背景层全部**静止化**（保留视觉，去掉 animation/will-change，保留一次性栅格化的 blur）；② 顶栏去掉 `backdrop-filter`（滚动时逐帧重模糊的主因），改用 `rgba(255,255,255,.9)`；③ 顶栏过渡不再动 `backdrop-filter`；④ 移除 logo `breathe`；⑤ 全站 `transition: all` 收窄为显式属性；⑥ TemplateSquare 去掉 `will-change`（保留 `translateZ(0)`）。
- 构建：dist `index-BI6Ck2iG.css` / `index-KpKeHxcf.js`（exit 0）。

### 追加：胶囊内"框中框"根因 + 首页鼠标跟随卡顿
**1) 胶囊内出现"框中框"（下拉聚焦时）**
- 根因：`App.vue` 全局 `.ant-select-focused:not(.ant-select-disabled).ant-select:not(.ant-select-customize-input) .ant-select-selector { box-shadow: 0 0 0 3px rgba(61,107,255,.1) !important }` 特异性为 **5**（:not 参数计权），而胶囊里我写的 selector 覆盖只有 **4** → **聚焦时全局规则胜出**，在胶囊内部画出内层聚焦环。
- 修：用**双类名**把覆盖特异性提到 6：
  `.type-selector-item.type-selector-item :deep(.type-select.ant-select-focused .ant-select-selector)`（首页）
  `.input-actions-center.input-actions-center :deep(.model-select.ant-select-focused ...)`（对话页）
  并同时覆盖 `:hover` / `.ant-select-open`。
- 教训：覆盖 `.ant-*` 时，注意 `:not()` 内部的类**计入特异性**；全局 `-focused` 规则(5)比常规 base 规则(3)高一大截。

**2) 首页交互卡顿 —— mousemove 逐帧写 CSS 变量**
- `HomePage.vue` 原来 `onMounted` 里监听 `mousemove`，每次把 `--mouse-x/--mouse-y` 写到 `document.documentElement`；而 `#homePage::after`（`position:absolute; inset:0; z-index:2`）用这两个变量做 `radial-gradient` 定位 → **每次移动鼠标都触发整屏样式重算 + 全屏重绘**。
- 修：删除监听/清理逻辑与 `onUnmounted` 引入，光晕改为**固定位置**静态渐变。
- 附：`ant-design-vue` 4 的 CSS-in-JS 会给组件根加哈希类（如 `.css-1p3hq3p`），其规则特异性 +1，覆盖时需留意。
- 构建：dist `index-li0k-OZO.css` / `index-D1PiCNLj.js`（exit 0）。

## Vue 生成代码质量保障（依赖/组件/语法体检 + 修复闭环）
- 背景：用户为 VUE_PROJECT 模式的系统提示词放开组件库约束后，构建成功率明显下降。用户诉求"加几个 skill 检查依赖引入/组件使用/语法"。
- 我的判断：**只靠提示词（软校验）不可靠**；应做"提示词约束(防) + 确定性脚本校验(查) + LLM 修复闭环(补)"三层。用户确认按此执行，交付形态 = 集成到平台后端流程。
- 交付：
  1. `scripts/vue-code-guard.mjs`（ESM，Node18+）：三类检查
     - dependency：扫描 import/require **并从模板组件标签前缀反推所需组件库**（关键：AI 常"用了组件却忘写 import"，只扫 import 会漏）
     - component：模板组件是否 import / main.ts 是否 app.use() 全局注册；组件名是否命中已知清单（识别幻觉组件名，warning）
     - syntax：`.vue` 用 @vue/compiler-sfc parse+compileScript+compileTemplate；`.ts/.js` 用 esbuild transformSync
     - 输出：人类可读 / `--json`（含 type/severity/file/line/message/hint，供修复闭环消费）；exit 0/1/2
  2. `docs/codegen/vue-codegen-guard.md`：生成约束提示词片段（可直接塞后端系统提示词）、修复提示词模板、后端编排伪代码、误报防护说明。
  3. `package.json` 加 `"guard"` 脚本入口。
- **踩坑记录（重要）**：
  - `@vue/compiler-sfc` 3.5 的 `parse()` 返回 `{ descriptor, errors }`，**不是** descriptor 本身（旧版 3.x 才是）。
  - `esbuild` 的 `transform` 是**异步**返回 Promise，同步 try/catch 抓不到 → 必须用 `transformSync`。
  - 依赖提取正则会误伤注释/字符串中的引号文本 → 需先剥离注释 + 用行首锚点匹配 import/export。
  - 必须跳过路径别名 `@/xxx`（否则 `@/api` 被当成缺失 npm 包），但 `@scope/name` 是真包不能误伤。
  - SVG 元素（ellipse/path 等）、router 全局组件（RouterLink）需加入白名单，否则大量误报。
- **真实收益**：在本项目上跑，查出 2 个真实隐患 —— `@ant-design/icons-vue`、`dayjs` 代码里 import 了但 package.json 未声明（靠 antd 传递依赖 hoisting 才能构建，换 pnpm/严格安装即失败）。已补进 dependencies（dayjs ^1.11.13、icons-vue ^7.0.1，与已装版本一致）。修复后本项目的体检结果 = 0 错误 0 警告。
- 验证：造"问题样本"能抓出全部 3 类（含幻觉组件名 warning），"健康样本"零误报；真实项目误报从 22 → 0。构建 exit 0。
